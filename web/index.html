hpcc

A distributed compiler cache that a regulated security team will actually approve.
Sandboxed remote compilation · per-tenant KVM boundary · auditable by row.

Install

Run this on any Linux or macOS host. It downloads the right binary for your platform, walks you through configuring as a client / worker / scheduler, and runs hpcc init with your answers.

curl -fsSL https://hpcc.dev/install.sh | bash

To pin a specific release instead of the latest:

curl -fsSL https://hpcc.dev/install.sh | HPCC_VERSION=v0.1.0-alpha bash

What it does

The installer is plain bash with no dependencies beyond curl and unzip (or bsdtar). It reads input from /dev/tty so the curl pipe doesn't eat your answers. Source is on GitHub — feel free to read it before piping into bash.
